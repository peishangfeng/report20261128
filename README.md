# 在日中国朝鮮族メディアの変遷

裴尚峰、2026年11月28日。日本語のWebスライド（全4枚）。

- [公開スライド](https://peishangfeng.github.io/report20261128/)
- PC：左右キーまたは画面下のボタンで移動。対応ブラウザーでは F キーで全画面。
- スマートフォン：画面上の章タブか画面下のボタンで移動。

## 写真・リンクの更新

1. 補足リンクと写真は `resources.html` の該当章に追記します。本編の `index.html` を変更する必要はありません。
2. 掲載許可のある写真を `assets/` に追加し、画像の説明（`alt`）、撮影者、出典リンク、許諾・ライセンスを記載します。許可が不明な場合は 元の掲載先へリンクします。
3. GitHub Pages は `main` ブランチの `/` を公開します。更新を `main` に反映すると再公開されます。
4. 表紙QRコードは公開トップURLを指し、写真・資料の追加では変更不要です。

発表者用のメモ、添付の元ファイル、連絡先などは公開サイトに含めていません。会場写真の出典・ライセンスは資料ページに記載しています。
